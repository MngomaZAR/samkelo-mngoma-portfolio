# Samkelo Mngoma | Professional Portfolio

Public, responsive CV and selected-work portfolio. Built as a lightweight static site for GitHub Pages, without trackers, a backend, or account credentials.

## Content

- `index.html`: professional profile, experience, selected work and interview video.
- `styles.css`: accessible, responsive screen and print styles.
- `Samkelo-Mngoma-CV.pdf`: two-page, text-based CV for recruitment.
- `build_cv.py`: reproducible PDF authoring source (Python + ReportLab).
- `assets/`: public-entry screenshots of the featured projects.

## Maintenance

Edit the public text in `index.html` and the CV text in `build_cv.py` together. Run `py -3 build_cv.py` to rebuild the PDF. Check the PDF and mobile/desktop layout before publishing. GitHub Pages publishes the repository's `main` branch at `/`.
